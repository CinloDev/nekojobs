# ✨ Features

## 💼 Application Tracker

Manage every opportunity from first contact to final decision.

Track:

- Company.
- Position.
- Job URL.
- Application source.
- Technologies required.
- Salary expectations.
- Notes.
- Current status.

Supported states:

```
Saved
↓
Applied
↓
Contacted
↓
HR Interview
↓
Technical Interview
↓
Technical Test
↓
Offer
↓
Rejected
```

## 📊 Career Analytics

Understand your search with data.

NekoJobs helps answer questions like:

- Which platforms generate more opportunities?
- Which technologies appear most frequently?
- How many applications become interviews?
- What companies respond more often?
- How long does it take to receive feedback?
